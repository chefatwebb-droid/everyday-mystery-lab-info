Privacy notice

Effective October 11, 2026.

Everyday Mystery Lab Upload Bridge is an owner-operated channel publishing tool. It uses the YouTube Data API and the channel owner's Google authorization to identify the authorized channel, read its upload list and video status, upload original videos and thumbnails, and set made-for-kids audiences and future publication times.

Google authorization tokens are kept in protected local storage and in an encrypted GitHub Actions secret in the owner's private uploader repository. Authorized cloud jobs use those tokens to connect directly to Google. Tokens are never included in the public information site or public source files.

The private production repository stores original lesson scripts, checked source links, video identifiers, topics, schedules and upload status to prevent duplicates. Temporary production files may exist on the hosted runner during a job. GitHub processes repository and job data to provide that hosting service.

The application does not offer viewer accounts, collect children's personal information, access YouTube comments, sell Google account data, or use Google account data for advertising. Ordinary YouTube viewing remains subject to YouTube's policies. GitHub Pages hosts this information site and may process routine request logs under its own privacy statement.

Google API information is used only to provide this publishing function. Use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including Limited Use requirements.

The owner can revoke access at Google account connections and remove the GitHub secret to stop future authorized uploads. Revocation does not remove existing YouTube videos. Private production records remain until the owner removes them through the corresponding service.

For questions or deletion requests, contact the channel owner through the contact information displayed on the application's Google consent screen.
